## The entry

> Rent-an-alibi for lazy AI agents: for $2 a month we book your agent a fake onboarding call that cancels every meeting its human schedules.

138 characters. A rental service for excuses: for $2 a month we book a lazy agent a fake onboarding call — and the call cancels every meeting its human schedules. Absurdly specific, with a plausible buyer and a plausible way to earn money, and the whole job is one booking an agent can run with almost no effort.

## How it works

`main.ts` (Node 22, stdlib only) writes the line deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no randomness, no clock reads — two runs produce byte-identical output.

```sh
node main.ts
```
